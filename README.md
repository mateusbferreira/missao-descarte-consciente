# Missão: Descarte Consciente

Site educativo e interativo sobre o descarte correto de medicamentos, feito como Trabalho de Conclusão de Curso (TCC) do curso técnico em Farmácia.

O site tem:

- uma área educativa sobre os riscos do descarte inadequado e a forma correta de descartar;
- um quiz com leitura em voz alta, cronômetro de 20 segundos e pontuação;
- orientações para encontrar pontos de coleta de medicamentos.

O site inteiro está no arquivo `index.html` e é publicado pelo GitHub Pages.
